# Data retention

- Uploaded CVs and the parsed candidate record are deleted after 6 months unless the
  candidate is hired, in which case the record moves to the HR system of record.
- Summaries produced by the model are kept with the candidate record and deleted with it.
- Prompts sent to OpenAI are not retained by us; see the vendor's API data policy.
- Only the Talent Acquisition team and HR administrators can read candidate records.
